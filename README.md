# Aprendiendo PlayWright

## ¿Para qué es este repositorio?
Este repositorio es para hacer ejercicios de testing automatizado con Playwright y TypeScript.

## ¿Qué conocimientos se aplicarán?
Para ello se aplicarán los conocimientos adquiridos de la plataforma [TAU (Test Automation University)](https://testautomationu.applitools.com/playwright-intro/),

## ¿Cómo lo haremos?
Para poder aplicar los casos de test, se usará la página: https://demo.playwright.dev/todomvc

## ¿Qué pasos realizaremos?
1. Crearemos nuestra carpeta de repositorio
2. Iniciaremos el proyecto dentro de la carpeta del repositorio con el comando de la terminal :

**npm init playwright@latest**

Con ello se crearan las carpetas y archivos de configuración para nuestro proyecto Playwright con TypeScript

3. A partir de ahí, se empezarán con casos sencillos y básicos, correspondientes al curso de introducción.

4. Después se aplicarán los conocimientos del curso avanzado.

5. Poco a poco se irán añadiendo más recursos, ya que la idea es aplicar conocimientos de GitHub/GitLab, APIs, CI/CD, etc.# aprendiendo_playwright

6. También se ha añadido una carpeta para generar los logs de cada ejecución de los tests y tener un histórico de los mismos. A medida que vaya avanzando en los estudios, se irá mejorando la gestión de los logs y lo que muestran en el fichero.


La idea es ir afianzando los conocimientos poco a poco con una práctica real y no solo viendo videos. Mejorando la programación de test y haciendo que los procesos de creación de test y gestión del desarrollo sean cada vez más fluidos sin tener que revisar tanto mis notas.
